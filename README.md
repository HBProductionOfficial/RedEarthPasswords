# Red Earth Passwords

Red Earth / ウォーザード (War-Zard) password generator. Customize your character
easily and see what any password does.

**English domain:** <https://redearthpassword.vercel.app>

**Japanese domain:** <https://warzardpassword.vercel.app>

## How the passwords work

Ten symbols, each one a button on the panel, carrying a level, a VS point total
and three numbers that decide the extras, interleaved in a different order for
every character. [The long version is on the site.](https://redearthpassword.vercel.app/en/how-it-works)

## Accuracy

The rules were recovered by disassembling the game. They are checked against
real passwords: 225 from published lists all decode, and the 129 of those that
state a level all decode to that level.

The level progression, meaning titles, weapons, shields, moves and resistances, is
research rather than disassembly, and the page says so where it matters.
